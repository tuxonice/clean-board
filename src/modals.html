Vertically Centered

This modal is vertically centered in the viewport, which works well for short confirmation dialogs or simple messages.

Static Backdrop

This modal will not close when clicking outside of it. The user must explicitly dismiss it using the button or the close icon. Useful for forms requiring deliberate action.

Small Modal

A compact modal-sm dialog. Ideal for brief confirmations or alerts.

Default Modal

The default modal width (~500px). No size modifier needed.

Large Modal

A modal-lg dialog (~800px wide). Good for data-heavy content like tables or multi-column forms.

Extra Large Modal

A modal-xl dialog (~1140px wide). Useful for dashboards, editors, or full data previews inside a modal.

Fullscreen Modal
Takes up the entire viewport. Suitable for immersive editors, media viewers, or wizard flows.
